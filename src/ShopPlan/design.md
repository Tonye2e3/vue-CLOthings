# 電商首頁設計需求

請建立一個現代、極簡風格的電商首頁，設計靈感參考 UNIQLO 的品牌識別與版面架構。

## 設計美學與 UI 指南

採用日系極簡風格，保留充足留白、高對比字體，以及俐落的網格分隔線。

**色彩配置：**

- 純白背景（`#FFFFFF`）
- 深灰黑文字（`#111111`）
- 淡灰色邊框（`#E5E5E5`）
- 鮮明紅色強調（`#E60012`），用於折扣標籤或活動徽章

**字體設定：**

- 使用清晰易讀的無襯線字體（Helvetica、Arial 或 Noto Sans TC）

## 頁首與導覽列

固定（sticky）置頂導覽列，包含：

- **左側**：方形簡約 Logo 區塊（佔位）
- **中間**：分類選單（Home、Shop、Community、GroupBuying）
- **右側**：功能圖示（搜尋、收藏、帳號、購物車）

## 主視覺區（Hero 輪播）

滿版寬度的生活風格圖片輪播（carousel），圖片上方帶有柔和文字覆蓋，內容包含：

- 商品或系列名稱（例如：「輕便抗UV連帽外套」）
- 標語（Tagline）
- 價格（例如：「NT$1,290」）
- 活動標示（例如：「團購優惠至 8/6」）

## 內容區塊與版面配置

### 限時優惠與特價專區

採用響應式四欄商品卡片網格，每張卡片包含：

- 商品圖片
- 活動標籤（例如：「新品上市」或「期間限定」）
- 商品名稱
- 補充描述
- 價格標示

### 聯名／UT 系列橫幅區

- 雙欄大圖展示區（2-column layout）
- 用於呈現聯名或設計師系列（例如：CLOthings）

### 分類展示區

- 以簡潔卡片形式呈現不同族群分類（依性別／年齡區分）

## 頁尾（Footer）

**結構化連結區塊：**

- 客服中心
- 常見問題（FAQ）
- 公司資訊
- 隱私政策
- 電子報訂閱

**社群媒體圖示列：**

- Facebook、Instagram、LINE、YouTube

**版權資訊區塊**

## 技術需求

- 使用 Vite + Vue.js 建立前端開發環境，採用現代化組件化架構設計。
- 採用 JavaScript 作為主要開發語言，實現互動功能與頁面邏輯。
- 使用 CSS 進行客製化樣式設計，打造符合品牌風格的響應式介面。
- 整合 Lucide Icons 圖示庫，提供簡潔一致的 UI 圖示體驗。
- 使用 Framer Motion 實現流暢的頁面動畫效果，包括滑動轉場、Hover 互動效果與微動畫設計。
- 支援完整響應式設計（Responsive Design），確保網站能於手機、平板及桌面裝置上提供一致且最佳化的使用體驗。
